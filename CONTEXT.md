# Ink

Ink is a TypeScript and React framework for Light Phone III apps. It provides UI components and device APIs.

## Language

**Ink app**:
A Light Phone III application built with Ink. It uses React semantics. React Native native modules are not supported.

**Ink screen**:
A page of app content presented within Ink's shared phone interface. The shared interface includes typography, spacing, scrolling, navigation controls and keyboard handling.

**Native capability**:
A device or platform API, such as camera capture or audio playback. An available API can still require user permission.

**LightOS integration**:
Access to LightOS preferences, permissions and services. LightOS integration does not grant distribution approval.

**App appearance**:
An Ink app's choice of light or dark interface colours. It is distinct from the user's LightOS invert-colours preference, which the inspected SDK does not expose.
