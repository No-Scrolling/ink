Run `bun test/android/run.ts --serial emulator-5554` from the repository root. Android tests are opt-in and require an explicit serial, Bun, `adb`, JDK 17 or 21 (`JAVA_HOME`), Android SDK platform 36 and build tools (`ANDROID_HOME`), and an API 34+ device. Start the prescribed emulator with `emulator -avd Light_Phone_III -writable-system` and wait for boot before running. Gradle may download its pinned build dependencies on first use.

The standalone fixture compiles the real production Kotlin adapters directly and installs `com.vandam.ink.contracttests`. The runner refuses to replace an existing package, takes a per-device lock, and uninstalls its fixture in `finally`. It does not start or stop an emulator or change device settings. Build and instrumentation logs remain in `.test-output/android/`. If a run is forcibly interrupted, explicitly uninstall the fixture and remove its `.test-output/android-<serial>.lock` directory before retrying.

The 15 device contracts cover SQLite persistence, competing compare-and-set writes, version and size rejection, notifications to live sibling stores, Handler timeouts and cancellation, late-result ownership, duplicate IDs and completion, pending-request capacity, JSON escaping and the UTF-8 message limit, Android Keystore persistence and authentication, managed-file confinement, managed ranges, local camera response bytes, queued upload cancellation, upload limits and disposal, real HTTP request/response bytes, and idle stream/upload cleanup. The expiry check waits the real 61 seconds; no clock or scheduler is replaced. The controlled queue used for cancellation is the adapter's injected Executor and runs the actual production file operation.

This fixture exercises adapter and platform contracts without Rust/JNI or application rendering. It does not claim full end-to-end bridge coverage, cross-process store notification coverage, media/hardware coverage, image preparation coverage, or release network-policy coverage. Its debug HTTP request uses device loopback, which production permits for development; it needs no public network service.
