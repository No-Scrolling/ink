## Ink

This is a Light Phone III app built with [Ink](https://ink.noscroll.ing).

- Read `node_modules/ink/DESIGN.md` before you design, add or change a page, and follow it. Write its page map before writing screen code.
- Build pages from Ink's components. Use only the props in their type definitions.
- Run `ink check` and fix every `ink-design` error before reporting work as done.
