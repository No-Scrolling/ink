<p><code>ReorderList</code> displays labels with up and down arrows. It handles spacing, scrolling and moving items.</p>

## Example

```tsx app/index.tsx
import { useState } from "react";
import { ReorderList, Screen } from "ink";

export default function Reordering() {
  const [items, setItems] = useState([
    { id: "1", name: "Item 1" },
    { id: "2", name: "Item 2" },
    { id: "3", name: "Item 3" },
    { id: "4", name: "Item 4" },
  ]);

  return <Screen title="Reordering">
    <ReorderList
      items={items}
      keyExtractor={item => item.id}
      getLabel={item => item.name}
      onChange={setItems}
    />
  </Screen>;
}
```

<p>Use a unique, stable ID for each item. <code>onChange</code> receives a new array in the selected order.</p>

<p>This example keeps the order until the app closes. Use <a href="/store">Store</a> to save it between sessions.</p>
