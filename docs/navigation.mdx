## Open and close pages

A file in `app/` defines a page. Export its React component as the default. Use `href` to open it from a button:

```tsx
<Button href="/settings">Settings</Button>
```

This opens `app/settings.tsx`. To navigate inside a handler:

```tsx
import { navigate } from "ink";

navigate("/settings");
```

Return to the previous page:

```tsx
import { back } from "ink";

back();
```

Replace the current page without adding to the history:

```tsx
import { replace } from "ink";

replace("/");
```

The header Back button and left-edge swipe leave the page, including when the keyboard is open. Hardware Back dismisses the keyboard first.

## Page paths

| File | Path |
| --- | --- |
| `app/index.tsx` | `/` |
| `app/settings.tsx` | `/settings` |
| `app/settings/units.tsx` | `/settings/units` |
| `app/album/[id].tsx` | `/album/123`, with a different ID for each album |
| `app/(tabs)/index.tsx` | `/`; parentheses group pages without changing their paths |

Keep only one file for each path. Files beginning with `_` are ignored except `_layout.tsx`. See [Project structure](/project-structure) for supporting files and folders.

## Dynamic pages

Use `[id]` in the filename when multiple items share a screen:

```tsx
import { navigate } from "ink";

navigate({ path: "/album/[id]", params: { id: album.id } });
```

Read the ID inside `app/album/[id].tsx`:

```tsx
import { useRouteParams } from "ink";

const { id } = useRouteParams("/album/[id]");
```

The ID is a string. Use it to load the album, and handle missing data on the page. Pass IDs and small JSON values rather than entire objects.

### Route rules

Static paths take priority: `/album/new` opens `new.tsx` before `[id].tsx`. Duplicate patterns and repeated parameter names are errors. Optional and catch-all segments are not supported.

`navigate()` and `replace()` check required path parameters in TypeScript and at runtime. Numeric IDs become strings; encoded path segments are decoded.

`useRouteParams(path)` supplies types from the path but does not check that the file exists. For other parameters, pass a `decode(unknown)` function to validate them. A generic type alone does not validate data. Invalid notification routes show “Page unavailable”.

## Layouts

Add `_layout.tsx` when pages need shared state. `Slot` renders the current page inside it.

This layout uses your `AccountProvider` component:

```tsx app/_layout.tsx
import { Slot } from "ink";
import { AccountProvider } from "../components/AccountProvider";

export default function Layout() {
  return <AccountProvider><Slot /></AccountProvider>;
}
```

Layouts are optional. The root layout stays mounted during navigation. A nested layout stays mounted while any of its pages remain in the navigation history.

### Tab-bar actions

Add `Tabs.Action` alongside the tab declarations for a button that opens another page:

```tsx
<Tabs.Action icon={photoCamera} onPress={() => navigate("/scan")} />
```

Import `photoCamera` from `ink/icons` and `navigate` from `ink`. Back returns from Scan to the selected tab. Actions keep the inactive colour and never become selected.

### Show, hide and reorder tabs

Use React conditions or array mapping to choose tabs. Keep at least one visible tab; actions do not count. Give mapped tabs and actions stable keys.

| Change | Result |
| --- | --- |
| Reorder tabs | Keeps the selected tab and its state. |
| Remove a tab | Unmounts its content. Removing the selected tab selects the first remaining tab. |
| Navigate to an omitted page | Opens it without the tab bar. Back returns to the previous page. |
| Hide the index tab at startup | Opens the first visible tab without mounting the index page. |

Load saved tab preferences before rendering `Tabs`. Explicit navigation and incoming links can still open an omitted page. Actions follow declaration order but do not affect startup selection.

### Tab history

Switching tabs preserves their state. Navigating to an existing tab group selects the tab and closes pages above it, without adding another copy of the group. This also applies to `replace()`.

## Screen state

Hidden pages and layouts keep React state and pause effects. Tabs also keep their scroll positions. Removing a page from the history unmounts it.

Use [Store](/store) to keep data after the app closes. When saving a setting, await the update before `back()`; Ink shows the updated value as the previous screen returns.

## External actions

```tsx
import { openURL, share } from "ink";

await openURL("https://example.com");
await share({ text: "Hello from Ink" });
```

Web links open in an Android Custom Tab whose toolbar follows Ink’s colour scheme. Telephone links open the dialler; message links open a composer. Other app schemes use their installed handlers. Use [Files and media](/files) to share attachments.

Both functions return promises. Cancellation resolves normally; missing handlers and native failures reject. Web links also reject when Custom Tabs is unavailable. File, content, script and intent URLs are not allowed.

These imports include the native external capability and browser package queries.
