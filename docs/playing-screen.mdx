## Native playback clock

`PlayingScreen` reads the native clock from its playback binding. Apps do not pass position, speed or seek handlers separately. See [native playback progress](/audio#keep-visual-progress-native).

Custom players implement the exported `Playback` interface: state, `toggle()` and `seek()`. Optional `previous()`, `next()` and `seekBy()` methods enable the corresponding buttons. Native clock bindings remain internal to Ink players. Custom players and controlled previews render their supplied state.

Transport commands and bottom actions may return promises. The screen prevents overlapping commands, shows failures and retries the command that failed. App-specific commands supplied in the binding still run, including persistence and sleep-timer logic.

## Upcoming artwork

Pass up to two cover sources in `preloadImages`, such as the next and previous tracks. Ink prepares them at the playing screen’s image size and keeps the current cover visible while a replacement loads.

```tsx
<PlayingScreen image={track.artwork} preloadImages={nearbyCovers} {...playbackProps} />
```

## Bottom actions

<div className="pattern-example">
<div>

<p>Actions are spaced evenly at the bottom. Use <code>selected</code> for an underline, or change the icon.</p>

<p>Use <code>label</code> instead of <code>icon</code> for text actions, such as playback speed or download progress. Numbers align automatically.</p>

```tsx
import { repeatFilled, repeatOneFilled, shuffleFilled } from "ink/icons";

const actions = [
  { icon: shuffleFilled, selected: shuffled, onPress: toggleShuffle },
  { icon: repeatOne ? repeatOneFilled : repeatFilled,
    selected: repeating, onPress: cycleRepeat },
];
```

Transport controls default to `{ kind: "track" }`, which calls the matching `previous()` or `next()` method on `playback`. `{ kind: "skip", seconds: 10 }` calls `seekBy()` with the matching direction and interval. Unavailable methods disable the control.

Use `{ kind: "custom", icon, onPress }` for a custom transport action. Its icon and handler are explicit, so there is no default action to override. Every variant accepts `onLongPress` and `disabled`; long presses remain separate from taps.

## Title and artists

Use `onTitlePress` for the track title and an `onPress` on each artist to open their pages. An image reserves its space while loading.
