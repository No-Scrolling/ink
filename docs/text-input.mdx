## Example

<div className="pattern-example">
<div>

<p>Place inputs on their own page, with hints or errors underneath.</p>

```tsx app/index.tsx
import { useState } from "react";
import { Screen, TextInput } from "ink";

export default function Search() {
  const [query, setQuery] = useState("");

  return <Screen title="Search">
    <TextInput
      value={query}
      onChange={setQuery}
      placeholder="Search"
      action="search"
    />
  </Screen>;
}
```

## Keyboard action

<div className="pattern-example">
<div>

<p><code>action</code> chooses the bottom-right keyboard key: <code>"search"</code> for a magnifying glass, or <code>"done"</code> for a tick.</p>

<p>Both call <code>onSubmit</code> with the entered text. Without it, they dismiss the keyboard.</p>

<p>Use <code>action="return"</code> for new lines. Add a header <code>rightAction</code> to save or continue. The input grows to three lines, then scrolls.</p>

```tsx
import { check } from "ink/icons";

<Screen
  title="Note"
  rightAction={{ icon: check, onPress: () => save(note) }}
>
  <TextInput
    value={note}
    onChange={setNote}
    placeholder="Write a note"
    action="return"
  />
</Screen>
```

<p><code>save</code> is your function to save the text and leave the page.</p>

## Numbers

<div className="pattern-example">
<div>

<p>Use <code>inputMode="numeric"</code> for digits only. The value remains a string.</p>

```tsx
<TextInput
  value={value}
  onChange={setValue}
  placeholder="Enter a number"
  inputMode="numeric"
  action="done"
/>
```

## Prefix and suffix

<div className="pattern-example">
<div>

<p>Use <code>prefix</code> and <code>suffix</code> for fixed text. Neither is included in the value.</p>

```tsx
<TextInput
  value={value}
  onChange={setValue}
  placeholder="Amount"
  inputMode="numeric"
  action="done"
  prefix="£"
  suffix="GBP"
/>
```

## Hints and errors

<div className="pattern-example">
<div>

<p>Place a small <code>Text</code> component below the input.</p>

```tsx
<Stack gap={12}>
  <TextInput
    value={name}
    onChange={setName}
    placeholder="Name"
    action="done"
    onSubmit={value => setError(
      value.trim() ? "" : "Enter a name."
    )}
  />
  <Text size={20}>
    {error || "Use up to 30 characters."}
  </Text>
</Stack>
```
