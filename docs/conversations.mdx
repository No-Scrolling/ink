## Example

<div className="pattern-example">
<div>

<p><code>ConversationScreen</code> provides the message list, composer and actions page.</p>

```tsx app/index.tsx
import { useState } from "react";
import { ConversationScreen, type ConversationMessage } from "ink";

export default function Chat() {
  const [messages, setMessages] = useState<ConversationMessage[]>([
    { id: "1", text: "Have you listened to this album yet?",
      timestamp: Date.now() },
  ]);
  const [draft, setDraft] = useState("");

  return <ConversationScreen
    title="Alex"
    messages={messages}
    draft={draft}
    onDraftChange={setDraft}
    onSend={({ text, replyTo }) => {
      setMessages(current => [...current, {
        id: String(Date.now()), text, timestamp: Date.now(),
        outgoing: true,
        reply: replyTo ? {
          author: replyTo.outgoing ? "You" : "Alex",
          text: replyTo.text || "Photo",
        } : undefined,
      }]);
      setDraft("");
    }}
  />;
}
```
<p>This example adds messages locally. Connect <code>onSend</code> to your messaging service to send them.</p>

</div>

## Message status

<div className="pattern-example">
<div>

<p>Set <code>status</code> on outgoing messages.</p>

| Status | Display |
| --- | --- |
| `sending` | Single tick in inactive grey |
| `sent` | Single tick |
| `delivered` | Double tick |
| `read` | Eye |
| `failed` | “Tap to retry” when `onRetry` is supplied; otherwise “Could not send” |

```tsx
<Message text="See you soon" timestamp={Date.now()}
  outgoing status="delivered" />
```

<p>Failure text replaces the timestamp. Failed messages have no icon.</p>

## Message details

Every message needs a stable `id` and a `timestamp` in milliseconds since the Unix epoch. Ink shows local time for today and adds the month and day for older messages. `reactions` adds text to the same information line.

Use `actions(message)` for extra message actions, `onAttach` for the plus button, and `onDoubleTap` for double taps. Ink returns to the chat before running a custom action.

Set `rightAction={{ icon, onPress }}` to add a header action, as with [Screen](/screens).

`onLoadOlder` returns a promise and prepends older messages; `hasOlder` says whether more remain. Ink loads history and nearby images ahead of view, preserving scroll position and momentum.

`loading` shows initial loading content; `sending` disables the send action.

`Message` is also available separately for custom screens.

## Link previews

<div className="pattern-example">
<div>

<p>Tapping a card opens its URL. Use <code>onPress</code> for a custom action. Supply the title and image yourself; Ink does not fetch page metadata.</p>

```tsx
import { LinkPreview } from "ink";

<LinkPreview
  url="https://www.youtube.com/watch?v=-zjJpFYtx9s"
  title="Arson as a Christmas Tradition: The Gävle Goat"
  image={{
    src: "https://i.ytimg.com/vi/-zjJpFYtx9s/hqdefault.jpg",
    width: 480,
    height: 360,
  }}
/>
```

</div>
<div className="pattern-preview">
<img src="/images/patterns/link-preview.png" alt="A YouTube preview card with the Gävle Goat thumbnail, video title and domain." width="1080" height="1240" />
</div>
</div>

Use `icon={favicon}` to add a site icon.

In a conversation, pass the same data as the message's `linkPreview`. The card replaces its URL in the displayed text. Tapping uses `onLinkPress` if supplied; long-pressing opens message actions.
