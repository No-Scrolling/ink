## Example

```tsx app/index.tsx
import { Screen } from "ink";
import { Video } from "@ink/video";
import video from "../assets/video.mov";

export default function Watch() {
  return <Screen title="Video">
    <Video src={video} />
  </Screen>;
```

## Sources

Import `.mp4`, `.mov` or `.webm` files, or pass an HTTPS URL:

```tsx
import { Video } from "@ink/video";

<Video src="https://example.com/video.mp4" />
```

Local file and content URIs are also supported. Development builds allow localhost HTTP URLs.

Format support depends on the device's codecs.
