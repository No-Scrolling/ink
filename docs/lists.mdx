## Example

<div className="pattern-example">
<div>

```tsx app/index.tsx
import { List, Screen, Text } from "ink";

const items = Array.from({ length: 20 }, (_, index) => ({
  id: String(index),
  name: "Item " + (index + 1),
}));

export default function Items() {
  return <Screen title="Items">
    <List
      items={items}
      keyExtractor={item => item.id}
      renderItem={item => <Text>{item.name}</Text>}
    />
  </Screen>;
}
```
<p>Rows are virtualised and measured automatically. Give each item a unique, stable key.</p>

</div>

## Pagination

<div className="pattern-example">
<div>

<p><code>onLoadMore</code> runs as the reader approaches the bottom. Append the returned items and set <code>hasMore</code> to false after the last page.</p>

```tsx
<List
  items={items}
  keyExtractor={item => item.id}
  renderItem={item => <Text>{item.name}</Text>}
  onLoadMore={loadNextPage}
  hasMore={hasMore}
/>
```
<p><code>loadNextPage</code> must return a promise. Ink allows one request at a time and shows a retry action if it fails.</p>

</div>

## Updating items

Replace arrays and changed items instead of mutating them. Rows outside the visible window unmount, so keep lasting state in the parent or a store. Ink preserves the visible position when earlier rows load or change height.

Use `onLoadOlder` and `hasOlder` to prepend history. [Conversations](/conversations) handle this for chats. `initialEnd` mounts the last rows first; it does not scroll the screen on its own.

Use `measurementKey` when a setting changes row layout without changing the items. Give the list a new React `key` when changing its data source. Keys and content versions have a combined 128 KiB limit; keep keys short and loaded history bounded.
