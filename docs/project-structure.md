---
title: "Understand your files"
description: "Know what to edit and what Ink generates."
---

A new app has one screen:

```text
my-app/
  app/
    index.tsx
  ink.toml
  package.json
  tsconfig.json
  README.md
```

| File or folder | What it does |
| --- | --- |
| `app/index.tsx` | Your home screen |
| `app/` | Pages; each page exports a React component |
| `ink.toml` | App name, Android identifier, version and release signing |
| `package.json` | Packages your app uses and local SDK resolution |
| `tsconfig.json` | TypeScript settings; keep its `ink/tsconfig` extension |
| `bun.lock` | Exact installed package versions; keep it in version control |
| `node_modules/` | Installed packages; generated by Bun |
| `.ink/` | Generated entry point and build files; do not edit |
| `dist/` | Built APKs, the files you install on a phone |

As your app grows, put reusable components in `components/`, data and helper functions in `lib/`, and your own pictures in `assets/`. These folders are optional. Keep non-page files outside `app/` so they do not become routes.

You do not need `App.tsx` or a handwritten entry point. An optional `app/_layout.tsx` can wrap pages in a shared provider or define tabs. Start without it until you need that behaviour.

When adding a grouped home page such as `app/(tabs)/index.tsx`, move or remove the original `app/index.tsx`: both resolve to `/`. Parenthesised groups organise files without adding a URL segment.
