title: "Rows"
description: "Display a title, subtitle and optional image."
---

## Example

<div className="pattern-example">
<div>

```tsx app/index.tsx
import { Row, Screen } from "ink";
import artwork from "../assets/wallsocket.jpg";

export default function Albums() {
  return <Screen title="Albums">
    <Row
      image={artwork}
      title="Wallsocket"
      subtitle="underscores"
      href="/album"
    />
  </Screen>;
}
```
<p>Create <code>app/album.tsx</code> for the destination. Use <code>onPress</code> instead of <code>href</code> to run an action.</p>

</div>
