## Example

<div className="pattern-example">
<div>

```tsx app/index.tsx
import { Field, Screen } from "ink";

export default function Settings() {
  return <Screen title="Settings">
    <Field label="Units" href="/units">Metric</Field>
    <Field label="Location">London</Field>
  </Screen>;
}
```
<p>Use <code>href</code> to open an editing page, or <code>onPress</code> for an action. Place the input on the editing page.</p>

</div>

## Images

Use `image` to show a picture before the label, such as an app's icon. It takes the same sources as `Image`: a bundled asset, a managed file or an HTTPS URL.

```tsx
<Field label="Maps" image={app.icon} onPress={choose}>M</Field>
```
