## Loading

<div>

```tsx
<Screen title="Forecast">

    : <Text>18°C and sunny</Text>}
</Screen>
```

## Empty

<div className="pattern-example">
<div>

```tsx
<Screen title="Saved places">
  <EmptyState title="No saved places"
    action={{ label: "Add a place", onPress: addPlace }} />
</Screen>
```

</div>
<div className="pattern-preview">
<img src="/images/patterns/empty.png" alt="No saved places with an Add a place action." width="1080" height="1240" />
</div>
</div>

Place loading, empty and error states directly inside `Screen`. They replace its content. Keep existing content visible during background refreshes; use [Resources and actions](/data) to track loading and failures.

`ErrorState` accepts `retryLabel` and `disabled`. `EmptyState` accepts an optional `description` and `action`. These components display state; they do not fetch data.
