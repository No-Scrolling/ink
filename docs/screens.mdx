## Header actions

Use `leftAction` and `rightAction` for header buttons. Back takes precedence over `leftAction` on detail screens.

```tsx
import { Screen, navigate } from "ink";
import { graphicEq, sort } from "ink/icons";

<Screen
  title="Albums"
  leftAction={{ icon: sort, onPress: () => navigate("/albums-sort") }}
  rightAction={{ icon: graphicEq, onPress: () => navigate("/playing") }}
>
  {/* Screen content */}
</Screen>
```

## Stacks

<div className="pattern-example">
<div>

<p>Use <code>Stack</code> to group content. Set <code>axis="horizontal"</code> for a row.</p>
<p>Set <code>onPress</code> to make the whole group tappable, including gaps between its children.</p>

```tsx

  <Text>London</Text>
  <Text size={18}>United Kingdom</Text>

## Tabs

<div className="pattern-example">
<div>

<p>Declare tabs in <code>_layout.tsx</code>. Each name refers to a neighbouring page.</p>

import { Tabs } from "ink";

export default function Layout() {
  return <Tabs>
    <Tabs.Screen name="index" icon={homeFilled} />
    <Tabs.Screen name="settings" icon={settingsFilled} />
  </Tabs>;
}
```

## Spacing and appearance

Screens and lists share a default gap of 47 logical units. `Stack` accepts `gap`, `align` and `justify`. Use `gap={0}` for compact groups; do not add padding around content already padded by the screen.

### Colour scheme

Use a [toggle](/toggles) to switch between light and dark mode.

```tsx
import { Screen, Toggle, setColourScheme, useColourScheme } from "ink";

export default function Appearance() {
  const scheme = useColourScheme();

  return <Screen title="Appearance">
    <Toggle label="Light mode" value={scheme === "light"}
      onChange={light => setColourScheme(light ? "light" : "dark")} />
  </Screen>;
}
```

The choice lasts for the app session. Use [Store](/store) to save it between sessions. Photos and codes retain their original colours.

## Loading images

Screens wait up to one second for their first visible images before appearing. Failed images do not block the screen. Images reached by scrolling load normally.

To show content immediately:

```tsx
<Screen title="Show" waitForImages={false}>
  <Image src={show.artwork} width={100} height={100} fit="cover" />
  <Text>{show.title}</Text>
</Screen>
```
