## Wrapping and truncation

<div className="pattern-example">
<div>

<p>Text wraps automatically. Set <code>maxLines</code> to limit the number of lines.</p>

```tsx
<Text maxLines={1}>
  Take the coastal path past the harbour and follow the signs to the lighthouse.
</Text>
```

## Tabular numbers

<div className="pattern-example">
<div>

<p><code>tabularNumbers</code> gives digits equal widths so numbers do not shift as they change.</p>

```tsx
<Text tabularNumbers>{frequency.toFixed(2)} Hz</Text>
```

</div>
<div className="pattern-preview">
<img src="/images/patterns/text-numbers.png" alt="340.00 Hz and 350.00 Hz with aligned digits." width="1080" height="1240" />
</div>
</div>

Use `width` for fixed columns. In a horizontal `Stack`, text without a fixed width shrinks to leave room for neighbouring controls. Nested `Text` uses the outer text style.
