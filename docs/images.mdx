## Example

<div className="pattern-example">
<div>

<p>Import the image from your assets folder. Set its width and height.</p>

```tsx app/index.tsx
import { Image, Screen, Stack } from "ink";
import artwork from "../assets/wallsocket.jpg";

export default function Artwork() {
  return <Screen title="Image">
    <Stack align="center">
      <Image src={artwork} width={240} height={240} />
    </Stack>
  </Screen>;
}
```

## Sources

`src` accepts imported assets, HTTPS URLs and Ink-managed image sources from Camera or Files. Arbitrary `file://` paths are not supported. Width and height must be positive.

Recently displayed images are cached in memory, so returning to a page can reuse them. Change the URL when remote image content changes.
