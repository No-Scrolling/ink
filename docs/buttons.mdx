## Example

<div className="pattern-example">
<div>

```tsx app/index.tsx
import { useState } from "react";
import { Button, Screen } from "ink";

export default function Counter() {
  const [count, setCount] = useState(0);

  return <Screen title="Counter">
    <Button onPress={() => setCount(count + 1)}>
      Count: {count}
    </Button>
  </Screen>;
}
```

<p>Use <code>onPress</code> for an action, or <code>href</code> to open a page.</p>

```tsx
<Button href="/settings">Settings</Button>
```

## Long press

Use `onLongPress` for an additional action, such as opening an options menu. A long press does not trigger `onPress`.

```tsx
<Button onPress={openPass} onLongPress={openOptions}>
  Membership
</Button>
```
